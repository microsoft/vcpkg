# Open3D vcpkg Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add and validate an `open3d` vcpkg port from the merged Open3D `main` revision, with an opt-in `cuda` feature and GUI disabled until Filament is available.

**Architecture:** Package Open3D with the standard vcpkg CMake helpers. The port pins the merged upstream commit, enables Open3D's vcpkg dependency mode, maps the vcpkg `cuda` feature to `BUILD_CUDA_MODULE`, and follows the selected vcpkg library/CRT linkage. Version metadata is generated by vcpkg after the two port files are complete.

**Tech Stack:** vcpkg manifests and portfiles, CMake, Open3D CMake build, CUDA Toolkit 13.0 on the current host.

### Task 3: Add the Open3D CMake portfile

**Files:**
- Create: `ports/open3d/portfile.cmake`

- [ ] **Step 1: Add the pinned source download, feature mapping, and CMake recipe**

Create `ports/open3d/portfile.cmake` with:

```cmake
string(COMPARE EQUAL "${VCPKG_LIBRARY_LINKAGE}" "dynamic" OPEN3D_BUILD_SHARED)
string(COMPARE EQUAL "${VCPKG_CRT_LINKAGE}" "static" OPEN3D_STATIC_WINDOWS_RUNTIME)

vcpkg_check_features(
    OUT_FEATURE_OPTIONS FEATURE_OPTIONS
    FEATURES
        cuda BUILD_CUDA_MODULE
)

vcpkg_from_github(
    OUT_SOURCE_PATH SOURCE_PATH
    REPO isl-org/Open3D
    REF df18cd291b996035267672d4fbf847095d057f4a
    SHA512 c26eee0623f235f1d96056c1d106476a72d6191a6a13affdfea22a3824a3ffc19f9cfda84bb78df80c0541535783fe99d2e8c1a0671e131fe893920b54533e4a
    HEAD_REF main
)

vcpkg_cmake_configure(
    SOURCE_PATH "${SOURCE_PATH}"
    OPTIONS
        -DBUILD_SHARED_LIBS=${OPEN3D_BUILD_SHARED}
        -DOPEN3D_USE_VCPKG=ON
        -DBUILD_EXAMPLES=OFF
        -DBUILD_UNIT_TESTS=OFF
        -DBUILD_BENCHMARKS=OFF
        -DBUILD_PYTHON_MODULE=OFF
        -DWITH_STUBGEN=OFF
        -DBUILD_GUI=OFF
        -DBUILD_WEBRTC=OFF
        -DBUILD_JUPYTER_EXTENSION=OFF
        -DBUILD_ISPC_MODULE=OFF
        -DWITH_IPP=OFF
        -DWITH_MINIZIP=OFF
        -DBUILD_LIBREALSENSE=OFF
        -DBUILD_AZURE_KINECT=OFF
        -DBUILD_TENSORFLOW_OPS=OFF
        -DBUILD_PYTORCH_OPS=OFF
        -DBUNDLE_OPEN3D_ML=OFF
        -DBUILD_FILAMENT_FROM_SOURCE=OFF
        -DBUILD_VTK_FROM_SOURCE=OFF
        -DUSE_SYSTEM_VTK=ON
        -DDEVELOPER_BUILD=OFF
        -DSTATIC_WINDOWS_RUNTIME=${OPEN3D_STATIC_WINDOWS_RUNTIME}
        ${FEATURE_OPTIONS}
)

vcpkg_cmake_install()
vcpkg_copy_pdbs()

if(VCPKG_TARGET_IS_WINDOWS)
    vcpkg_cmake_config_fixup(CONFIG_PATH CMake)
else()
    vcpkg_cmake_config_fixup(CONFIG_PATH lib/cmake/Open3D)
endif()

vcpkg_fixup_pkgconfig()

file(REMOVE_RECURSE
    "${CURRENT_PACKAGES_DIR}/debug/include"
    "${CURRENT_PACKAGES_DIR}/debug/share"
)

vcpkg_install_copyright(FILE_LIST "${SOURCE_PATH}/LICENSE")
```
